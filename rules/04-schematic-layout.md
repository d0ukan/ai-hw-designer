## 04 · Schematic, Component Placement & Routing

- [ ] **SCH-01** — Split the schematic into functional blocks; use consistent net names, references and necessary notes. Prefer hierarchical sheets for complex circuits; do not create unnecessary sheets for small boards.
- [ ] **SCH-02** — Verify component properties, pinouts and footprint dimensions against the manufacturer datasheet of the relevant MPN. Record the verified source, revision and relevant page briefly; do not re-research existing reliable information unnecessarily.
- [ ] **SCH-03** — **PI / power tree:** Produce a short power tree listing, for each rail, the source, loads, total current, regulator capacity and margin, ripple/noise limit and power-up sequence. Add the datasheet-recommended ferrite/LC filter or a separate LDO to analog, PLL, ADC reference and RF rails.
- [ ] **SCH-04** — **Decoupling:** Place the datasheet-recommended local capacitor on every supply pin (typically 100 nF if none is given) and a bulk capacitor on every rail. In the schematic, draw the capacitor next to the IC pin it serves and make clear which pin it belongs to; layout follows this pairing (LAY-25).
- [ ] **SCH-05** — **SI preparation:** For clocks and fast-edge signals, leave a series termination position near the driver (typically 22–33 Ω or 0 Ω). Calculate I²C pull-up values from speed and bus capacitance. Choose low-capacitance ESD protection for fast interfaces. Connect unused and strapping/reset/boot pins per the datasheet; do not leave inputs floating.
- [ ] **SCH-06** — **Mark constraints in the schematic:** Mark differential pairs with `_P/_N` (or the names the EDA expects) and critical nets with a net class or rule note (Power, Diff/HS, RF, HV); generate layout rules from these marks.
- [ ] **SCH-07** — **Option positions (0 Ω / DNP):** At points whose value or need is uncertain, place a 0 Ω bridge or an unpopulated (DNP / N/A) part position: e.g. series termination, pull-up/pull-down, filter, impedance matching (pi/L), configuration selection, measurement point. Mark DNP parts clearly in the schematic and BOM. Use these positions only for real uncertainty; do not add unnecessary parts, area and cost.
- [ ] **SCH-08** — **User schematic check (before G0.5, optional):** After the schematic review PASS, ask: **"The schematic is done. Do you want to check it?"** If the user says no, write "user skipped the schematic check" into the G0.5 evidence and continue. If yes, the Designer exports a draft `Review/<rev>/<prefix>_SCH-draft.pdf` and one PNG per sheet (`<prefix>_SCH-p1.png` …) and shows the images in the chat. Give a short summary: blocks, main parts, power paths, how the review findings were closed, and the net list for the main nets (SCH-12). Ask the user to open the schematic in the EDA tool (name the file) and to approve it or ask for changes. Changes go back to the Designer and the Reviewer re-checks them. Write the user's schematic OK into the G0.5 evidence; do not start layout while the user's requested changes are open. Without file or tool access (web chat), tell the user how to export the PDF/PNG and ask them to share them.
- [ ] **SCH-09** — **Wires first, few labels:** A human must be able to follow every connection by eye. Inside a functional block, connect with real wires. Use net labels only between blocks that are far apart or on different sheets, and for buses. Use hierarchical sheets, harnesses and global labels only when the design really needs them (large or multi-sheet designs). Never build a block from labels alone.
- [ ] **SCH-10** — **Power and layout:** Show supplies (VBAT, 3V3, GND …) with power symbols, not net labels. Signal flow left to right (input → protection → control → output); higher voltage at the top, GND at the bottom. Group each functional block together with a short text title. Keep symbols and wire ends on the EDA's standard grid (KiCad 1.27 mm / 50 mil). Put a junction dot on every T connection; never connect wires at a crossing (4-way).
- [ ] **SCH-11** — **Readable text:** No text overlaps another text, symbol, wire or pin. Reference and value sit next to their part, horizontal where possible; standard text size (KiCad 1.27 mm). Move fields of parts placed close together (e.g. parallel capacitors) so each value is clearly assigned. Place PWR_FLAG and no-connect markers so they do not cover other text.
- [ ] **SCH-12** — **Self-check after drawing (AI, MCP):** After each drawing step export the sheet as PNG and look at it: fix overlaps, label-only blocks, off-grid or dangling wires. Run ERC and fix or explain each warning. Give a short net list for the changed nets (net → part.pin) so the user and the Reviewer can confirm the connections without guessing. Do not hand over a schematic that fails SCH-09…11.
- [ ] **SCH-13** — **Differential pairs visible in the schematic:** Draw the two lines of a pair side by side along the same path, with series parts (common-mode choke, series resistor, AC capacitor) placed as matching pairs. Next to each pair put a short text note with interface and impedance, e.g. "USB D+/D− · 90 Ω diff", "CAN · 120 Ω diff", "LVDS · 100 Ω diff". Name the nets so the EDA recognizes the pair (DIF-09) and assign them to the Diff/HS net class (SCH-06). A reader must see from the drawing alone which nets are differential pairs.
- [ ] **SCH-14** — **Standard sheet and title block:** Every sheet uses the same template from [Hardware-Library/sheet-templates/](../Hardware-Library/sheet-templates/README.md) (KiCad: `hfa-title-block.kicad_wks`). Paper A4 landscape; A3 only for a crowded sheet. The title block shows project name, project code, revision, variant, sheet name, sheet x/y, date, designer and reviewer, filled from the project identity (INT-49); none is left empty. Keep the EDA's default text sizes, line widths and colors; do not restyle per project.
- [ ] **SCH-15** — **Fixed sheet order, one block per sheet:** (1) Cover: block diagram, revision history, general notes; (2) power input and protection; (3) regulators and power rails; (4) MCU / main IC; (5…) interfaces, RF and sensors, one functional block per sheet; (last) connectors, mechanical parts (mounting holes, fiducials, logos) and test points. Small boards may merge sheets in this order. Each block has a short title on its sheet; sheet names match the blocks.

### General

- [ ] **LAY-01** — Place decoupling capacitors as close as possible to their supply pins; keep the current return path short.
- [ ] **LAY-02** — Size power traces and power vias for current carrying, voltage drop and temperature rise requirements.
- [ ] **LAY-03** — Place sensitive analog circuits, noisy digital circuits and switching power supply areas appropriately.
- [ ] **LAY-04** — Preserve the reference planes and return paths of signal traces.
- [ ] **LAY-05** — Avoid unnecessary 90° corners during routing; prefer 45° transitions where possible. Use mitered or curved bends on RF traces (section 05, RF-06).
- [ ] **LAY-06** — Provide accessible test points for supply rails and critical signals.
- [ ] **LAY-07** — Show component references, Pin 1 and polarity marks on the silkscreen, legible and not overlapping pads.

### Placement

- [ ] **LAY-08** — **Reference layout:** If the component's datasheet, application note or evaluation board recommends a placement/routing, use it as the basis. Apply it as-is if the board's area, volume, layer or mechanical constraints allow, otherwise the closest equivalent; record the differences and their justification. State the source name and revision in `Project-README.md`.
- [ ] **LAY-09** — Placement order: first mechanically fixed parts (connector, mounting hole, button, LED, display, antenna), then power input and protection, then main ICs, last passives. Place input protection (fuse, TVS, reverse polarity) closest to the connector; no unprotected trace may enter the board.
- [ ] **LAY-10** — In switching regulators, keep the high di/dt loop (input capacitor – switch – diode/low-side FET) in the smallest area and follow the datasheet layout example. Keep the SW node small; do not route sensitive traces under or beside it. Take the feedback trace from the output capacitor/load and route it away from the SW node and inductor.
- [ ] **LAY-11** — Place the crystal/oscillator close to its IC pin, with the load capacitors adjacent. Do not route other signals under or near it; follow the datasheet recommendation for GND guarding and keepout.
- [ ] **LAY-12** — Spread out heat-generating parts (regulator, power FET, LED driver); provide datasheet-compliant thermal vias and copper area under thermal pads. Keep heat-sensitive parts (crystal, reference, sensor, electrolytic) away from hot zones.
- [ ] **LAY-13** — Place similar parts in the same orientation and aligned; use a consistent orientation for polarized parts. If single-sided assembly was chosen, put all SMD parts on the same side. Model connector, test point and button access mechanically; check component-to-board-edge distance against panel/V-cut and manufacturer limits.

### Routing

- [ ] **LAY-14** — Routing order: first critical traces (RF, differential pairs, clock, switching and high current), then sensitive analog, then general digital, last low-priority traces. Do not use the autorouter on critical traces; if used on other traces, review the result manually.
- [ ] **LAY-15** — Define net classes (e.g. Power, Signal, Diff/HS, RF, HV); set trace width, clearance and via size through net classes. Calculate power trace width from current and allowed temperature rise with IPC-2152 or the manufacturer's calculator; account for inner layers carrying less current.
- [ ] **LAY-16** — Layer usage: on 2 layers, keep the bottom layer as continuous GND as possible; keep bottom-layer jumps short. On 4 layers, the default stack is Signal / GND / PWR / Signal; route fast signals on the layer adjacent to GND. On adjacent signal layers, run traces perpendicular to each other.
- [ ] **LAY-17** — No signal may cross a split, slot or gap in its reference plane. If a trace changes layer and its reference plane also changes, place a GND return via next to the signal via (or a stitching capacitor between planes of different nets).
- [ ] **LAY-18** — Keep clocks and fast-edge signals short; leave at least 3W center-to-center spacing to other traces (≥ 2W edge-to-edge; EDA clearance is edge-to-edge) or guard them with GND; avoid long parallel runs. Do not leave unnecessary stubs, tree topologies or open-ended copper; if series termination is needed, place it near the driver.
- [ ] **LAY-19** — Route analog and sensitive traces (ADC input, reference, sensor, audio) away from noise sources. The default is a single, continuous GND; split AGND/DGND is applied only with datasheet or measured justification and a single connection point.
- [ ] **LAY-20** — Distribute power with wide traces or polygons; use enough parallel vias for the current; do not leave bottlenecks. Separate high-current return from sensitive GND return. Route current-sense (shunt) traces as separate Kelvin connections from inside the pads, close together and parallel.
- [ ] **LAY-21** — If high voltage is present, enter the approved clearance/creepage values (IPC-2221, IEC 62368-1 or the project standard) into the HV net class. Use an isolation slot if needed; keep HV traces away from the board edge and the low-voltage area.
- [ ] **LAY-22** — On small passives, enter both pads symmetrically with a trace narrower than the pad (reduces tombstoning and bridging risk). Do not leave acute-angle (acid trap) junctions. Use teardrops in the Aviation profile and at thin trace–via transitions. Do not use via-in-pad unless required (DFM-03); if mandatory, specify it to the manufacturer as filled & capped.
- [ ] **LAY-23** — **Shortest, direct path:** Connect the trace directly to the nearest same-net pad shown by the ratsnest; do not route traces that wander around the board, double back or change layers unnecessarily. If a detour is needed, first rotate/move the part or make an allowed pin/gate swap; fixing placement comes before lengthening the trace. On polygon nets such as GND, connect a nearby pad with the nearest via or polygon; do not route a long separate trace. Outside length matching, if a trace is longer than about 1.5 times the straight-line distance, reroute it or record the justification.
- [ ] **LAY-24** — **Free-angle / organic routing:** The default is 45° routing. In areas that need it (RF traces, curved/tight areas, flex, dense BGA breakouts), free-angle, curved (arc) or organic routing is asked of the user and applied if approved. Verify that the EDA tool supports it, DRC passes and the manufacturer accepts it.

### SI / PI (all boards)

- [ ] **LAY-25** — **PI:** Place each decoupling capacitor closest to its supply pin, the smallest value closest. The loop is pin → capacitor → GND via; put the via right next to the pad, connected short and wide; avoid sharing vias between capacitors where possible. Keep the power polygon/plane on the layer adjacent to the GND plane.
- [ ] **LAY-26** — **SI:** For a fast-edge signal, if the trace length exceeds the critical length (about `tr[ns] × 2.5 cm` in FR-4), treat the trace as a transmission line: apply controlled impedance, a continuous reference plane and termination (section 05). If you do not know the edge time, take it from the datasheet; do not guess.
- [ ] **LAY-27** — **Impedance matching:** For traces that need matching, handle three steps together: (1) in the schematic, define the source/load impedance and the matching network (termination, pi/L, DNP option if needed, SCH-07); (2) set the trace geometry from the approved manufacturer stack-up and a calculation tool (DIF-03…07, RF-03); (3) reduce discontinuities from vias, connectors, pads and layer transitions. Record calculations and assumptions; recalculate if the stack-up changes.
- [ ] **LAY-28** — **Length and delay matching:** On high-speed traces (e.g. USB, Ethernet, HDMI, MIPI, DDR, parallel bus), apply the intra-pair and intra-group tolerances from the interface specification. If traces pass through different layers, match delay (ps) instead of length; if the datasheet provides them, include package pin delay and via delay. Correct intra-pair mismatch close to where it occurs. When adding serpentines, keep at least 2W edge-to-edge (3W center-to-center) between bends and do not place them near pads/vias.
- [ ] **LAY-29** — **Completion check:** Unrouted net count is 0, DRC/ERC is clean or every exception is recorded with justification, polygons are repoured, no floating copper, no silkscreen on pads, no unnecessarily long/wandering traces per LAY-23, every decoupling capacitor close to its own pin per LAY-25, matching tolerances met per LAY-28. Record the result as Reviewer evidence.

### Silkscreen and marking

- [ ] **LAY-30** — Silkscreen is free of overlaps on each side: silk does not touch silk, pads, open mask, via openings or the board edge. Logo, board code, connector labels, designators and signature are included in this check; verify with DRC for each side. Bottom text is in the correct (mirrored) orientation.
- [ ] **LAY-31** — Apply the PCB-17…21 decisions: logo, board code, connector labels, designators and signature on the approved sides, at the approved size and position. For deferred decisions still unanswered, use the INT-51 safe default.
- [ ] **LAY-32** — **User PCB check (before G1, optional):** After the PCB review PASS, ask: **"The PCB is done. Do you want to check it?"** If the user says no, write "user skipped the PCB check" into the G1 evidence and continue to the G1 question. If yes, the Designer exports a draft `Review/<rev>/<prefix>_PCB-draft.pdf` and images (`_PCB-3D-top.png`, `_PCB-3D-bottom.png`, `_PCB-top.png`, `_PCB-bottom.png`; inner layers on request) and shows them in the chat with a short summary: size, layer count, connector positions, open DRC waivers. Ask the user to open the board in the EDA tool (and its 3D view) and to approve it or ask for changes. Write the user's OK into the G1 evidence. Skipping the check never skips the G1 approval itself. Same web-chat fallback as SCH-08. Drafts in `Review/` are not release outputs.
