# Mechanical & System CAD

This area stores only the mechanical sources and assembly work the project needs. Record the user-supplied enclosure, mounting interface, module/mating connector STEP data and the relative position references of the boards.

- Shared reusable component, module and connector models are kept under `Hardware-Library/models3d/`; do not duplicate the same CAD file without need.
- In a multi-PCB system, board IDs, mounting orientations and mechanical references must match `Project-README.md`.
- A full system CAD assembly is prepared if the user asks for it. Clearly mark approximate models without verified real dimensions and sources.
- The design review may include the required mechanical fit/collision check; the final STEP/CAD deliverable is created only for the user-approved scope and revision.

There are no empty/made-up 3D models here because there is no user CAD data or board design yet.
